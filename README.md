# Traffic Capture and Security Analysis Using Wireshark

## Overview
This project analyzes network traffic from a vulnerable web application (DVWA) using Wireshark. It focuses on identifying common security vulnerabilities such as plaintext credential exposure, insecure communication, and session hijacking risks.

## Tools Used
- Wireshark
- Kali Linux
- DVWA
- VirtualBox

## Key Analysis
- Captured and inspected HTTP requests and responses  
- Analyzed TCP handshake and network protocols (ARP, DNS, TCP)  
- Identified exposed credentials and session tokens  
- Demonstrated replay attack vulnerability  
- Discovered hidden directories using Gobuster  

## Key Findings
- Credentials transmitted in plaintext  
- Session tokens vulnerable to hijacking  
- No HTTPS encryption  
- Weak security configuration
